# v8 Rootkeeper Acceptance Checklist

| Criterion | How to assess |
|---|---|
| Body integrity | Inspect each frame during idle, stalk, attack, hit and defeat; no v7 torso cutouts or disjointed puppet holes |
| Attack choreography | Clear wind-up, forward sweep/impact, recovery; visual impact should align with damage event |
| Foot contact | Feet appear planted on actual ground, without large horizontal skating |
| Character identity | Rootkeeper retains its original foliage, bark, face, eye glow and claw silhouette |
| Gameplay unaffected | Collision, damage, boss HP, rune gates, educational questions and saves must match previous mechanics |
| Mobile performance | Safari and Android play smoothly with no broken image or missing assets |
| Education | All age/subject/language combinations remain functional |

**Review rule:** Any new transparent holes, severe texture deformation, sliding feet, frame drops or impact mistiming = **NO GO**. This v8 is a full-body deformation workaround, not a replacement for future professional character rigging.
